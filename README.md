# YALGO Portfolio Analyser

A command-line tool that reads your actual brokerage holdings, fetches live prices, and tells you what's going on with your portfolio — risk concentration, sector exposure, rebalancing ideas, and a long-term wealth projection — without you having to open five different apps to piece it together.

Built for the Indian market specifically: it understands statements from Kotak, CDSL (the consolidated account statement most Indian brokers can export), and Groww, plus a generic CSV format if your broker isn't one of those.

This is a personal project, not a product — it's the foundation for something bigger I'm building under YALGO Quant Labs, but right now it's just a tool I use to actually understand my own portfolio instead of guessing.

## What it actually does

You give it a holdings file. It gives you back:

- **Live prices** for everything you hold, pulled from a chain of sources so a single API going down doesn't break the whole report
- **Risk scoring** — how concentrated you are in one stock, one sector, how volatile the overall mix is
- **Sector breakdown** — where your money actually sits, not where you think it sits
- **Rebalancing suggestions** — if something's grown into an oversized chunk of your portfolio, it'll flag it and suggest what to trim
- **Log-normal projections** — bear/base/bull cases and percentile bands derived from a closed-form log-normal return model, scaled by the portfolio's own concentration risk, rather than a single flat "assume X% CAGR forever" number
- **A wealth goal tracker** — set a target (₹1 crore, retirement corpus, whatever) and it tells you if your current trajectory gets you there, and what you'd need to change if it doesn't
- **AI-generated commentary** — plain-language summary of what's going on, generated by an LLM that's been given your actual numbers, not generic advice
- **News context** — recent news for the stocks you actually hold, not a generic market feed

## How the pieces fit together

### Getting your data in

Indian brokers don't agree on a CSV format, so the parser has to handle several:

- **Kotak Portfolio Tracker** exports
- **CDSL CAS** (Consolidated Account Statement) — the one most brokers can generate, since it comes from the depository, not the broker
- **Groww** XLSX exports
- **A generic CSV** format, if you want to type your holdings in by hand or your broker isn't supported yet

The parser sniffs the file structure and figures out which format it's looking at rather than making you specify it.

### Getting live prices — the fallback chain

This was the trickiest part to get right, and it went through a lot of revisions. Live price fetching for Indian equities isn't reliable from any single free source, so instead of trusting one API, it tries several in order:

1. **Angel One SmartAPI** (primary) — this needed actual session handling: auto-generating TOTP codes, caching the session so it's not re-authenticating on every run, and resolving each symbol's instrument token from Angel One's own public scrip master (downloaded and cached for 24h) rather than a hand-maintained list, so any NSE-listed symbol resolves, not just a pre-selected set of large-caps
2. **NSE** direct
3. **Groww**
4. **Yahoo Finance**
5. **AI estimation** (last resort) — if every real data source fails, an LLM gives a rough estimate based on what it knows, clearly flagged as an estimate, not a real price

Every price that comes back gets run through a validator that rejects anything more than 20% off from the last known good price for that stock, and caches prices to disk with a 24-hour expiry so a slow or flaky source doesn't keep feeding stale numbers into the next run. This mattered more than it sounds — an early version of this tool was happily generating SELL signals based on prices that were actually a day old and just wrong.

There's also a hard rule that large-cap Nifty stocks are never allowed to fall through to AI estimation. If Reliance or HDFC Bank can't get a real price from four different live sources, something's wrong, and the tool should say so rather than quietly guessing.

### The analysis layer

Once it has reliable prices, it calculates:

- Position-level and portfolio-level risk scores
- Sector concentration, using one canonical sector-mapping function so the same stock can't get bucketed two different ways in two different reports
- Rebalancing alternatives — and specifically, if it's suggesting you reduce a position, it won't suggest moving that money into a stock you just sold (an actual bug that existed earlier)
- Log-normal projections for long-term outlook (bear/base/bull + percentile bands), not a single deterministic growth number

### AI recommendations — another fallback chain

Commentary and recommendations are generated by an LLM, using a 3-provider fallback (Groq → Mistral → Gemini, with the exact order depending on the task) so a single provider's outage or rate limit doesn't stop the report from generating. Anything based on an AI-estimated price (rather than a real one) is explicitly flagged as such in the output — recommendations don't get to pretend an estimate is a fact.

### Output

A generated report pulling all of the above together, plus relevant news for what you actually hold.

## Known limitations

Things this tool does not do, as a deliberate scope decision rather than an oversight:

- **Rebalancing alternatives don't exclude other stocks you already hold in the same sector.** It only filters out the exact stock being sold — if you hold two Financial Services stocks and one gets a SELL recommendation, the other can still show up as a suggested "diversification" alternative, which isn't really diversification.
- **The wealth roadmap's "years away" figures are capped at 50 years internally**, and that cap can print as if it were the real answer. A very small portfolio against a very distant target can show "~50Y" when the true figure is meaningfully higher — it's a search limit, not a computed result, in that case.
- **News relevance matching is a naive substring check** on the ticker and company name. Short tickers (LT, ITC) can match unrelated articles that happen to contain those letters inside ordinary words.
- **The symbol-name-to-ticker fallback covers roughly 100 hand-mapped names.** Anything outside that list, on a broker export that doesn't include ISIN, falls back to a regex heuristic that can produce a wrong symbol for a company it doesn't recognize.
- **Portfolio beta is computed but isn't fed into the projection model.** Beta comes from a fixed sector-average table; the log-normal projections scale volatility only off concentration (HHI), so the two don't currently inform each other.
- **Two different long-run return assumptions exist in the same report**: the wealth roadmap uses a flat 13% CAGR, the future-projections section uses 12%. Both are stated as assumptions, but they're not reconciled with each other.
- **`ISIN_TO_SYMBOL`'s mapping for ISIN `INE155A01022` still points to the retired `TATAMOTORS` ticker.** Tata Motors demerged in late 2025; the passenger-vehicle business relisted as `TMPV`. Whether this specific ISIN carried over to the new listing hasn't been confirmed against an authoritative source, so it's left as-is rather than guessed at — a CDSL CAS import against this ISIN may resolve to the wrong (dead) symbol until this is checked properly.
- **Live broker/exchange prices (Angel One, NSE, Groww, Yahoo) are now accepted without any independent plausibility check beyond a gross-corruption guard.** This is a deliberate trade, not an unexamined absence: the previous per-stock sanity bands were silently rejecting real, correct prices from the primary source (confirmed live for TCS and HDFCBANK), which is a worse failure than occasionally letting a bad quote from a regulated feed through unchallenged. If Angel One or a fallback source ever returns a wrong-but-plausible-looking number, this tool will report it as fact.

## Tech stack

Node.js / TypeScript. No database — it reads your holdings file, fetches what it needs, and generates a report. Nothing about your portfolio gets stored anywhere outside your own machine.

## Status

Functional and in active use. Recently went through a focused bug-fixing pass (15 fixes across the price validation, risk scoring, and sector logic) after finding several issues where stale or misattributed data was producing wrong signals — bad signals from a tool like this are worse than no tool at all, so that pass mattered more than any feature addition would have.

## Setup

```bash
npm install
cp .env.example .env   # add your own API keys
npm run build
npm start
```

This tool is built directly on top of specific providers — it's not "bring any AI key" or "bring any data source," the code expects these exact ones. Nothing will work out of the box without them, by design; this isn't meant to ship anyone else's credentials.

### Where to get each key

**Angel One SmartAPI** (primary live price source) — this one's more involved than a normal API key, since it's tied to an actual trading account:
1. Register at [smartapi.angelbroking.com](https://smartapi.angelbroking.com)
2. Log in, click **Create an App**, select the API type you need (Market Feed / Trading), give it a name, and provide your Angel One Client ID
3. Separately, enable TOTP at [smartapi.angelbroking.com/enable-totp](https://smartapi.angelbroking.com/enable-totp) using your Client ID and trading password/MPIN — this is what lets the code auto-generate session tokens instead of you logging in manually every run
4. You'll end up with an API key, API secret, your Client ID, and a TOTP secret — all four go in `.env`

This is free for Angel One customers. If you don't have real-time data access on your account, NSE/Groww/Yahoo fallbacks still work without it, but Angel One being down or unconfigured is the one most likely to actually matter, since it's first in the chain.

**Groq** (AI commentary, primary) — go to [console.groq.com](https://console.groq.com), sign up, open **API Keys**, click **Create API Key**. Free tier available, no card required, key takes about two minutes to generate.

**Mistral** (AI commentary, fallback) — go to [console.mistral.ai](https://console.mistral.ai), sign up (phone verification required), open **API Keys**, click **Create new key**. Free "Experiment" tier exists with a generous monthly token allowance, no credit card needed — though some setups require you to explicitly select a plan in the billing section before the key activates, even on free tier, so don't panic if a fresh key throws an auth error before you've done that.

**Gemini** (AI commentary, second fallback) — go to [aistudio.google.com](https://aistudio.google.com), sign in with a Google account, click **Get API key**, then **Create API key**. No credit card needed for the free tier. Rate limits vary by model and change periodically, so check the AI Studio dashboard for current numbers rather than trusting an old blog post.

**NewsAPI** (news fetching) — sign up at [newsapi.org](https://newsapi.org) for a free developer key. Free tier is rate-limited and meant for development, not production traffic, which is fine for personal use but worth knowing if requests start failing.

A failed or missing key for any single AI provider won't break the tool — that's the whole point of the fallback chain. A failed or missing Angel One key just means it falls back to NSE/Groww/Yahoo, which is slower and less reliable but still functional.
